1. 基本公式・演算子変換

項目公式・定義（隠れている時はクリックで表示）
光子のエネルギー・波数 $$E = h\nu = \frac{hc}{\lambda}, \qquad \nu = \frac{c}{\lambda}, \qquad \tilde{\nu} = \frac{1}{\lambda}, \qquad \hbar = \frac{h}{2\pi}$$
ド・ブロイ波長・量子化条件 $$\lambda = \frac{h}{p} = \frac{h}{mv}, \qquad 2\pi r = n\lambda \iff L = mrv = n\frac{h}{2\pi} = n\hbar \quad (n=1,2,\dots)$$
1次元の演算子ルール $$\hat{x} = x, \qquad \hat{p} = -i\hbar\frac{d}{dx}, \qquad \hat{T} = -\frac{\hbar^2}{2m}\frac{d^2}{dx^2}, \qquad \hat{H} = -\frac{\hbar^2}{2m}\frac{d^2}{dx^2} + V(x)$$
正準交換関係・不確定性原理 $$[\hat{x}, \hat{p}] = \hat{x}\hat{p} - \hat{p}\hat{x} = i\hbar, \qquad \sigma_x \sigma_p \ge \frac{\hbar}{2} \quad \left(\sigma_A = \sqrt{\langle \hat{A}^2 \rangle - \langle \hat{A} \rangle^2}\right)$$
規格化条件・期待値 $$\int_{-\infty}^{\infty} |\psi(x)|^2 dx = 1, \qquad \langle \hat{A} \rangle = \int_{-\infty}^{\infty} \psi^*(x)\hat{A}\psi(x)dx$$

2. 2大モデル（1次元の箱の中の粒子 vs 水素様原子）の比較

比較項目① 1次元の箱の中の粒子（幅 $a$）② 水素原子・水素様原子（核電荷 $+Ze$）
ポテンシャル $V$ $0 < x < a$ で $V(x)=0$（壁の外は $\infty$） $V(r) = -\dfrac{Ze^2}{4\pi\varepsilon_0 r}$（水素原子は $Z=1$）
波動関数 $$\psi_n(x) = \sqrt{\frac{2}{a}}\sin\left(\frac{n\pi}{a}x\right)$$ $$\Psi_{n,l,m}(r,\theta,\Phi) = R_{n,l}(r)\Theta_{l,m}(\theta)\Phi_m(\Phi)$$
※1s軌道：$R_{1,0}(r) = 2a_0^{-3/2}e^{-r/a_0}$
固有エネルギー $E_n$ $$E_n = \frac{h^2}{8ma^2}n^2$$（$n^2$ に比例して間隔が広がる） $$E_n = -\frac{m_e Z^2 e^4}{8\varepsilon_0^2 h^2}\frac{1}{n^2} = -\frac{\hbar^2 Z^2}{2m_e a_0^2}\frac{1}{n^2}$$（$n\to\infty$ で $0$：電離）
量子数の範囲 $n = 1, 2, 3, \dots$（$n=0$ や負は不適） $n = 1, 2, \dots$ ／ $l = 0, 1, \dots, n-1$ ／ $m = 0, \pm 1, \dots, \pm l$
節（ノード）の数 $n - 1$ 個 動径波動関数 $R_{n,l}(r)$ の節：$n - l - 1$ 個
代表値・特徴 $\langle x \rangle = \dfrac{a}{2}, \quad \langle p \rangle = 0$
$x=a/2$ で $n$奇数は偶関数、$n$偶数は奇関数		 ボーア半径 $a_0 = \dfrac{\varepsilon_0 h^2}{\pi m_e e^2} = \dfrac{4\pi\varepsilon_0 \hbar^2}{m_e e^2}$
1s動径分布 $g(r)=r^2|R_{1,0}|^2$ の極大は $r = a_0$

3. 頻出証明・導出 5パターン

パターン①：箱の中の粒子の波動関数とエネルギー導出（Day 3）

1. $0 < x < a$ で $V(x)=0$ より $-\dfrac{\hbar^2}{2m}\dfrac{d^2\psi}{dx^2} = E\psi \iff \dfrac{d^2\psi}{dx^2} = -k^2\psi \ \left(k = \sqrt{\dfrac{2mE}{\hbar^2}}\right)$
2. 一般解 $\psi(x) = c_1\cos kx + c_2\sin kx$ に境界条件 $\psi(0)=c_1=0 \implies \psi(x)=c_2\sin kx$
3. 境界条件 $\psi(a)=c_2\sin ka = 0 \implies ka = n\pi \ (n=1,2,\dots) \implies E_n = \dfrac{\hbar^2\pi^2}{2ma^2}n^2 = \dfrac{h^2}{8ma^2}n^2$
4. 規格化 $\int_0^a |c_2|^2\sin^2\frac{n\pi x}{a}dx = |c_2|^2\frac{a}{2} = 1 \implies c_2 = \sqrt{\frac{2}{a}}$

パターン②：箱の中の粒子の直交性の証明（必修 [3.6]）

$$\int_0^a \psi_m^*\psi_n dx = \frac{2}{a}\int_0^a \sin\frac{m\pi x}{a}\sin\frac{n\pi x}{a}dx = \frac{1}{a}\int_0^a \left\{\cos\frac{(m-n)\pi x}{a} - \cos\frac{(m+n)\pi x}{a}\right\}dx = 0 \quad (m \neq n)$$

パターン③：微分演算子 $\hat{A}_n = \frac{d^n}{dx^n}$ の固有値問題（必修 [2.4]）

1. $n=1$：$\dfrac{df}{dx} = af \implies \int\dfrac{df}{f} = \int adx \implies f(x) = Ce^{ax}$
2. 帰納法：$\hat{A}_{n+1}f = \dfrac{d}{dx}(\hat{A}_n f) = \dfrac{d}{dx}(a^n f) = a^n\dfrac{df}{dx} = a^{n+1}f \implies$ 固有関数 $Ce^{ax}$、固有値 $a^n$

パターン④：$1s$ 動径分布関数 $g(r)$ が $r = a_0$ で最大になる証明（[4.3]）

$$g(r) = |R_{1,0}(r)|^2 r^2 = \frac{4}{a_0^3}r^2 e^{-2r/a_0} \implies \frac{dg}{dr} = \frac{8}{a_0^3}r e^{-2r/a_0}\left(1 - \frac{r}{a_0}\right) = 0 \implies r = a_0$$

パターン⑤：ボーア模型の軌道半径とエネルギーの導出（[1.3]）

1. つりあい $\dfrac{m_e v^2}{r} = \dfrac{e^2}{4\pi\varepsilon_0 r^2} \implies E = \dfrac{1}{2}m_e v^2 - \dfrac{e^2}{4\pi\varepsilon_0 r} = -\dfrac{e^2}{8\pi\varepsilon_0 r}$
2. 量子化条件 $v = \dfrac{nh}{2\pi m_e r}$ をつりあい式に代入 $\implies r_n = \dfrac{\varepsilon_0 h^2}{\pi m_e e^2}n^2 = a_0 n^2$
3. $r_n$ を $E$ に代入 $\implies E_n = -\dfrac{m_e e^4}{8\varepsilon_0^2 h^2}\dfrac{1}{n^2}$
